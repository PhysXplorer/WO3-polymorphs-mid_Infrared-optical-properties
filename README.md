# WO3-polymorphs-mid_Infrared-optical-properties

This repository contains the tabulated frequency-dependent dielectric function and refractive index data for the three polymorphs of tungsten trioxide (WO3) at their respective temperatures, supporting the manuscript titled:

"First-Principles Prediction of Phonon-Mediated Infrared Optical Properties of WO3 Polymorphs"

## Contents

- `Optical_properties_data.xlsx`
  - Frequency-dependent dielectric function (real and imaginary parts)
  - Frequency-dependent refractive index (n) and extinction coefficient ($\kappa$)
  - Optical constants calculated using the full self-energy evaluation within third-order perturbation theory as implemented in TDEP
  - Experimental infrared reflectance (from FTIR) reported in DOI: 10.1016/S0013-4686(01)00364-4 for the monoclinic phase
  - Data for all three phases investigated in the manuscript, at their respective stable temperatures

The data correspond to the results presented in the manuscript and are provided to facilitate reproducibility and future use.
